# Handy 2 2.0.0

Handy 2 is a new app, built from scratch: control your Windows PC with a webcam. **All of the code was rewritten**; nothing is carried over from the first Handy.

## Features

- **Live camera** with the MediaPipe hand mesh and face landmarks drawn over the video
- **Mouse control** by hand or by head, with smoothing and sensitivity (off by default; F8 toggles it)
- **Wink and hand signs** trigger clicks, drag and scrolling; every gesture can be mapped to an action in the settings
- **Status line** under the video shows the detected gesture
- **Automatic updates** from GitHub releases: checked at start-up and daily, verified with SHA-256, and rolled back if an update is interrupted
